============================================================
2. PR #64 SCRATCH-ISOLATION DESIGN — ACCEPTED
============================================================

The correct fix is explicit benchmark scratch isolation, not a magic hard-coded /dev/shm path.

Accepted principles:

- real pilot requires explicit --scratch;
- ID files go under scratch;
- scratch must not share a physical disk with SNC data;
- output directory must not share the SNC data disk;
- physical-device resolution handles partitions and dm/md members;
- memory filesystems account for swap backing;
- unknown/ambiguous mappings fail closed;
- paths/device identities are recorded;
- sufficient scratch free space is checked.

Keep this design.

(EXEC refusals + INDEX refusals) / scheduled_in_window

G2 passes only if BOTH:

0.0002 = 0.02 percentage-point absolute per-rep ceiling above B max.

These are diagnostic telemetry non-perturbation tolerances only.

They are NOT campaign performance/materiality thresholds.
